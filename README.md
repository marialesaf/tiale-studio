# Tiale Studio — Páginas web a la medida

Landing del servicio de desarrollo de páginas web a la medida de Tiale.

Sitio de una sola página (HTML, CSS y JS en un solo archivo `index.html`), sin dependencias ni build. Para editarlo, abre `index.html` en tu editor.

## Secciones
- Hero
- Servicios
- Por qué código
- Proceso (4 pasos)
- Portafolio (carrusel)
- Testimonios
- Preguntas frecuentes
- Sobre nosotros
- Agenda (calendario + formulario)

## Publicar
Funciona en cualquier hosting estático (Vercel, Netlify, GitHub Pages). El archivo `.nojekyll` permite servirlo tal cual en GitHub Pages.
